# ICE Detention Map — frontend

React + TypeScript + Vite + Chakra UI + MapLibre GL single-page app. It renders
the static artifacts in `public/data/` (generated by `../pipeline/build_data.py`)
as proportional circles on a basemap, with a facility detail panel and
population history sparkline.

## Develop

```bash
yarn          # install
yarn dev      # dev server
yarn tsc -b   # type-check
yarn build    # production build (dist/)
```

To refresh the data the app serves, run the pipeline from the repo root:

```bash
pip install -r pipeline/requirements.txt
python pipeline/build_data.py
```

## Deploy

Deployed on Vercel with the project **Root Directory set to `web`** (framework
preset: Vite). Merges to `main` deploy automatically once the repo is imported
in the Vercel dashboard.
